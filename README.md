# How to Contribute
## Install git
- https://git-scm.com/download
## Clone the repository
- Open CMD
- Navigate to the folder you where you want to import the project using the `cd` command
  E.g. My development folder is `C:/Users/myname/Development`, so I navigate to there
- Run this command to clone this repository: `git clone https://github.com/Gearworks-Software/SJC-Mobile.git`
## Open in VSCode
- Open VSCode, of course
- Open the Folder created by the clone command earlier
## Contributing
### 1. Pull
- After cloning, you should have the latest version of the project if no one else has updated it; however, just in case, `pull` the latest version. ![image](https://github.com/user-attachments/assets/c04e1dd5-94a1-40ac-ba91-04c0705a3e11)
- Note that this image also shows 3 existing commits that have been pushed to the repository
### 2. Edit
- Make your changes, add features, fix bugs, change styles. Just work on your part of the project.
- Make sure you test
